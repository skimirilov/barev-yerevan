# Барев, Ереван

Культурно-образовательный маршрут по Еревану: пять дней, пять направлений культуры и пять ключей к душе города.

Сайт: https://skimirilov.github.io/barev-yerevan/

Готовый сайт находится в `barev-yerevan/dist/`. Фотографии, шрифты и пять интерактивных карт хранятся локально; ключи API и сборка не нужны.

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory barev-yerevan/dist
```

Откройте http://127.0.0.1:4173/.

## GitHub Pages

В Settings → Pages выбран источник GitHub Actions. Workflow `.github/workflows/pages.yml` публикует содержимое `barev-yerevan/dist/` после изменений в `main` или ручного запуска.

Визуальный дизайн адаптирован из предоставленного макета. Программа состоит из пяти вертикальных раскрывающихся глав. Поддерживаются русский и армянский языки, карточки 26 локаций и фильтры карт по дням и этапам.
