# Барев, Ереван

Статический сайт по вкладке **«Лендинг 2»**.

Опубликован на GitHub Pages: https://skimirilov.github.io/barev-yerevan/

## Запуск

Из папки `barev-yerevan`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. Для карт нужен HTTP-сервер: открытие HTML двойным щелчком не рекомендуется.

## Структура

- `dist/index.html` — страница и SEO-метаданные.
- `dist/style.css` — базовая адаптивная вёрстка.
- `dist/design-v2.css` — основа оформления по присланному макету: крупная типографика, графика и вертикальные главы.
- `dist/refinements.css` — палитра брендбука, анимации, мобильная вёрстка и блок организаторов.
- `dist/motion.js` — лоадер, появление текста, прорисовка пяти иллюстраций, плавное раскрытие и очистка обработчиков при смене языка.
- `dist/fonts.css`, `dist/assets/fonts/` — локальные Manrope и Noto Serif Armenian.
- `dist/app.js` — контент RU/ՀԱՅ, вертикальные главы, переключатели, карточки, взаимодействие с картами.
- `dist/data.js` — локации, описания, символы и их армянская версия.
- `dist/assets/` — оптимизированные фотографии, логотипы и favicon.
- `dist/maps/` — пять исходных комплектов карт; структура папок сохранена. В рабочие `map*.js` добавлен обмен сообщениями с родительской страницей для фильтрации, перевода карточек и переходов к точкам.
- `dist/program.txt` — доступная без JavaScript текстовая версия программы.
- `research/` — локальные исходные материалы и вспомогательные скрипты. Не нужны для публикации.

## Возможности

Шесть разделов в порядке ТЗ; два языка; пять вертикальных раскрывающихся глав программы; пять символов с раскрытием; 26 остановок; фильтры по дням и этапам; связь карточка ↔ маркер; локальные карты без API-ключей; настройка уменьшения движения; меню для телефона. WOW-точки выбраны редакционно и обозначены как наша подборка.

## GitHub Pages — следующий этап

Публиковать **содержимое `dist/`** через GitHub Actions либо поместить его в выбранную папку публикации. Все пути относительные: сайт работает и в подпапке репозитория. `.nojekyll` уже добавлен. Серверная часть, сборка, npm и ключи API не требуются. В репозитории настроена автоматическая публикация через GitHub Actions при обновлении `main`.

Перед публичным запуском желательна редактура армянского перевода носителем. Названия улиц на исходной картографической подложке сохранены из материалов автора карт. Участие, контакты и форма заявки не добавлялись: согласно ТЗ, нужны утверждённые организаторами данные.

## Палитра и движение

Бордовый `#681923`, синий `#2A658E`, кремовый `#F8F3E0`, оранжевый `#EF9346` по визуальному образцу брендбука (выбор подтверждён пользователем). На мобильных устройствах сокращены декоративные частицы. При `prefers-reduced-motion: reduce` анимации и лоадер отключены. Все шрифты и карты остаются локальными.
