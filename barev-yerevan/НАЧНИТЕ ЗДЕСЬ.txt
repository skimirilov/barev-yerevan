БАРЕВ, ЕРЕВАН — локальная версия сайта

1. Распакуйте архив целиком. Не меняйте структуру папок.
2. На компьютере должен быть установлен Python 3.
3. Windows: запустите «Запуск Windows.bat».
   macOS: запустите «Запуск.command» либо выполните команду ниже в Терминале.
   Linux: выполните команду ниже в терминале.
4. Откройте в браузере http://127.0.0.1:4173/
5. Оставьте окно сервера открытым, пока просматриваете сайт.

Ручной запуск из папки barev-yerevan:
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist

Windows (если команда python3 недоступна):
py -3 -m http.server 4173 --bind 127.0.0.1 --directory dist

Сайт, карты, фотографии и шрифты находятся в папке dist.
Для работы сайта интернет не требуется. Внешние ссылки требуют интернета.
Карты следует открывать через сервер, а не двойным щелчком по index.html.
Для будущей публикации на GitHub Pages используйте содержимое папки dist.
